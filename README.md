# MemeHunter

MemeHunter is a Solana memecoin trend-monitoring project with a Telegram interface and a web dashboard.

## Planned components

- Trend scanner for emerging public signals.
- Explainable scoring for novelty, momentum, saturation, and risk.
- Telegram alerts with links to original source posts.
- Web dashboard for opportunities and operational metrics.
- Isolated launch adapter, disabled until official interfaces, fees, and terms are verified.

## Safety

- Never commit seed phrases, private keys, bot tokens, or .env files.
- Enforce a maximum of five launches per day, spending limits, duplicate checks, confidence thresholds, and an emergency stop.
- No wash trading, fake volume, spam, or market manipulation.
- A launch does not guarantee buyers, volume, or creator-fee revenue.

## Local setup

Copy .env.example to .env and fill credentials locally. Never commit .env.

## Status

Initial repository scaffold. Integrations are not yet implemented.
